# Task 2 storage contract

- UUID primary keys are generated by application defaults. All timestamps use
  PostgreSQL timestamptz; created_at/updated_at default to database current time.
  SQLAlchemy updates updated_at on emitted updates. Direct SQL writers must set
  updated_at explicitly; child writes do not touch parent timestamps.
- A user has at most one assistant profile. Conversation ownership must match
  profile ownership, enforced by a composite foreign key.
- Names are 1–100 characters; preferred user name is optional (1–100 if set).
  Personality values are floats between 0 and 1, default 0.5.
- Language is a nonempty identifier up to 35 characters (default en); switching
  is follow_user or fixed. Custom instructions have a 10,000-character maximum.
  Greeting flags default false. Holiday preferences are a JSON object, default {};
  detailed preference validation belongs to the assistant API milestone.
- Preferred model is optional, 1–200 characters when provided. No provider model
  is frozen into the schema. Custom instructions default to the empty string.
- Message roles are user/assistant. Status is explicitly supplied as in_progress,
  completed, cancelled, or failed. Empty/partial content is valid and defaults to
  empty. Position is a positive conversation-local integer with a unique constraint;
  transactional allocation and lifecycle transitions belong to the pipeline.
- Users/profiles with dependent records cannot be deleted. Deleting a conversation
  cascades to its messages. No automatic user provisioning or HTTP APIs are added.

## Execution checkpoints

1. Record and review this contract; validate the unchanged foundation.
2. Add models and schema contract tests; run configured checks.
3. Connect Alembic metadata and add a reviewed initial migration; validate SQL.
4. Add live PostgreSQL persistence/constraint and migration-cycle tests; run all checks.
5. Document verified commands/results and perform final regression validation.

Each checkpoint is committed after its applicable validation passes.
